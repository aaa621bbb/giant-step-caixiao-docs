## 三条最容易踩的坑（每版都看一遍）

1. **缩放模型 → 衣服乱飞。** 永远缩世界，不缩模型。
2. **相机 near clip 和速度/眼高写死** → "什么都看不见""移动不了"。一切从身高推导。
3. **退出清理写不全** → 第二次进入越来越卡。零残留是硬指标。
