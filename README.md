## 阅读顺序

1. 先读 **v2.0 §1（现状诊断）** —— 弄清现有版本为什么玩不了。
2. 再读 **v2.0 §3 尺度系统** —— 这条错了后面全错。
3. 按 **v2.0 §12 分阶段实施** 开工，每阶段真机验证。
4. 内容扩充看 **v2.0 §7.5**，按 **§7.5.9 的 P0/P1/P2 优先级**推进，不要并行铺开。
5. 摆姿模块参考 **v0.1 第三节**。

## 三条铁律

1. **别真放大 PMX** —— 物理裙摆/IK/VMD 都是原生尺度，一缩放全崩。用"玩家 1.6m + 城市米制"来做巨人感。
2. **禁止魔法数字** —— 眼高、速度、碰撞体积全部从身高推导。
3. **每阶段必须真机验证** —— 上一版的问题就是攒到最后一起调，结果整个玩不了。
